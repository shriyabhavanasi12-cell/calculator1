A web-based scientific calculator built using HTML, CSS, and JavaScript. The project consists of basic arithmetic operations, scientific functions, and percentage calculations and trigonometric rules like sine, cos and tan


Features

Basic arithmetic operations: addition, subtraction, multiplication, and division.

Scientific functions including sine, cosine, tangent, and square root.

Percentage calculations and decimal values.

Parentheses for mathematical expressions.

Clear and delete buttons for editing calculations.

Error handling for invalid expressions and mathematical operations.



languages used: HTML,CSS,JavaScript
